# Endgame Index

A nightly, evidence-weighted reading of AI news against Max Tegmark's 12 possible endings for humanity and AI. It is a static site with no server, database or build step, so it runs free on GitHub Pages.

**Live at:** https://endgameindex.com (once the steps below are done)

## What's in here

| Path | Purpose |
|---|---|
| `index.html`, `assets/` | The website: Dashboard, Summary of the Day, History, Scoring Mechanism |
| `data/events/` | Rated news events, one file per day (**the nightly input**) |
| `data/summaries/` | Daily summaries and monthly recaps |
| `data/days/`, `data/history.json` | Generated by `scripts/compute.py`; do not edit by hand |
| `scoring/` | The published rules (`SCORING_RULES.md`) and their machine-readable twin (`rules.json`) |
| `scripts/compute.py` | The scoring engine: recalculates everything from the rules and events |
| `scripts/validate.py` | Pre-publish checks |
| `NIGHTLY_RUN.md` | The step-by-step playbook the 11:59 PM IST scheduled task follows |
| `CNAME`, `.nojekyll` | GitHub Pages settings for the custom domain |

## Publish it (one time, about 15 minutes)

### 1. Create the GitHub repo
1. On GitHub, click **New repository**.
2. Name it `endgame-index`, set it to **Public** (free Pages hosting needs a public repo on a free plan), and don't add a README.
3. Upload the contents of this folder to the repo root. The easiest ways are dragging the files into **Add file → Upload files**, or using GitHub Desktop. Include the hidden `.nojekyll` file.

### 2. Turn on GitHub Pages
1. In the repo, go to **Settings → Pages**.
2. Under **Source**, choose **Deploy from a branch**. Set the branch to **main** and the folder to **/ (root)**, then click **Save**.
3. After a minute the site is live at `https://<your-username>.github.io/endgame-index/`.

### 3. Connect endgameindex.com
1. At your domain registrar, open the DNS settings for endgameindex.com and add these records:

   | Type | Name | Value |
   |---|---|---|
   | A | @ | 185.199.108.153 |
   | A | @ | 185.199.109.153 |
   | A | @ | 185.199.110.153 |
   | A | @ | 185.199.111.153 |
   | CNAME | www | `<your-username>.github.io` |

2. In **Settings → Pages**, enter `endgameindex.com` as the **Custom domain** and click **Save**.
3. Once the DNS check passes, which can take anywhere from a few minutes to a few hours, tick **Enforce HTTPS**.

*(Check GitHub's current Pages documentation if these IP addresses have changed.)*

### 4. Give the nightly task permission to update the repo
1. On GitHub, go to **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. Under **Repository access**, choose **Only select repositories**, then pick `endgame-index`.
3. Under **Permissions**, set **Contents** to **Read and write**. Leave everything else at **No access**.
4. Set an expiry; you can renew it later. Keep the token private. It is only needed when the nightly task is set up.

## Preview it locally
```
python3 -m http.server 8000
# then open http://localhost:8000
```
Opening `index.html` directly from disk won't work, because browsers block `fetch()` of local files.

## Recompute after any change
```
python3 scripts/compute.py && python3 scripts/validate.py
```
